# Contributing to Mud Hut

Mud Hut is part of Neutron. One contributing guide covers all four Neutron repositories, and it lives
in the Neutron repository: [CONTRIBUTING.md](https://github.com/Nico-LaFoucate/Neutron/blob/main/CONTRIBUTING.md).

The short version:

- Sign off every commit (`git commit -s`, the Developer Certificate of Origin). There is no CLA.
- Test your change on a real Adobe app, and say in the pull request what you tested.
- Report bugs on this repository's [Issues](https://github.com/Nico-LaFoucate/Mud-Hut/issues/new/choose).
  An Adobe app misbehaving while running goes to
  [Neutron's Issues](https://github.com/Nico-LaFoucate/Neutron/issues/new/choose). Questions go to
  [Discussions](https://github.com/Nico-LaFoucate/Neutron/discussions).

Building and testing Mud Hut: `cargo build` and `cargo test`.
